## Data Changes

This AIRAC is for VATSIM only and only includes fixes to existing procedures and clients.

## Aerodrome

### NZAA: Auckland

#### RWY 23L

- The following RNP approaches have been fixed: `RNP S (AR)`.
    - `ZORBA` transition now properly changed to `AKDER` and procedure fixed to not always go through `AKDER`. Also `AA407` which was incorrectly part of the `AKDER` transition has been removed.

### NZQN: Queenstown

#### RWY 23

- The following SID has been fixed: `VAPLI3`
    - Waypoint `BIKOS` was renamed to `RIBDU` in a previous AIRAC but `LIBLA` transition was not updated. This has now been done.

## Standard Routes

No change.

## Other Dataset Changes

- Auckland (NZAA) vatSys maps for Night STARs was not being updated during AIRAC changes. This has not been fixed and future changes should now flow through automatically moving forward. Night STARs have also been removed from the main STARs map layer to remove confusion.
