This release updates all core Pacific data, as well as amending or removing changes made to the dataset in [the WorldFlight release](../2025/2511.md).

## Data Changes

- Updated the dataset to use the latest aeronautical data for the Pacific region.
- **Domestic Data**: Fixed an issue with the NZWR `HARBOUR 6` and `BREAM 6` SIDs that prevented export.
- Added a mock VOR entry for `NU VOR`, as the replacement of the VOR with a `RU` RNAV waypoint breaks airway parsing. This will be patched in our tooling.

SIDs and STARs often use Course to Altitude (CA) leg segments, which cause significant variance in the data for that aerodrome. Where multiple procedures at an aerodrome share similar CA termination points, these have been defined as a single pseduo-waypoint for all procedures for that runway. As these don't materially change the modelled procedures, they are not described below.

### Antarctica

!!! info "Adaptation of NZWD and NZFX Procedures"

    Due the difficulties in Antarctic navigation, many of the added procedures have been coded to terminate at `ZWD VOR` or `ZFX VOR`.

    Despite the navigation data being made available for Antarctica through Navigraph, the charts are not. Due to this, we have added a `MNLSID` and `MNLSTR` option for NZFX and NZWD. These are detailed on their [respective aerodrome pages](../../../antarctica/index.md).

- **NZFX**: The following STARs have been added: `CRSTI1`, `FABOS1`, `FAVGU4`, `GREES1`, `HEMAL1`, `HEMVI4`, `ZFX 8`
