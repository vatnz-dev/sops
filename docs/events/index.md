This area contains the operational material used when additional positions are activated for a VATNZ event.

## Before the Event

- Confirm the positions and frequencies approved for the event.
- Brief all controllers on the active runway mode and terminal-area split before the event begins.
- Use the event-specific briefing as the authority where it differs from the standard aerodrome SOP.

## Event Resources

- [Event positions](positions.md) lists the supplementary positions that may be activated.
- [Terminal areas](terminal-areas.md) provides the applicable terminal-area split diagrams.

!!! warning "Event-only positions"
    Event-only positions may only be staffed for an approved VATNZ event or with explicit authorisation from the Operations Director.
